## Roadmap подготовки к собеседованиям

1. **Основа — проект 1:** объяснить очистку, распределения, кодирование и корректную постановку статистической гипотезы. Исправить формулировку H0.
2. **Регрессия — проект 2:** объяснить Ridge/Lasso/ElasticNet, утечки, временную проверку и экономику качества.
3. **Классификация — проекты 3 и 4:** защитить выбор метрик, цену FN/FP, порог решения и ограничения ресурсов.
4. **Ансамбли — проект 5:** объяснить лес и бустинг, early stopping, сдвиг данных и ограничения интерпретации.
5. **Обучение без учителя — проект 6:** обосновать масштабирование, PCA, число кластеров и устойчивость сегментов.
6. **Нейросети — проект 7:** объяснить производные, Adam, Dropout и различия схем оценки.
7. **Перед публикацией:** обеспечить данные, зафиксировать зависимости, выполнить каждый ноутбук с чистого ядра и записать воспроизведённые результаты.

## Честное описание навыков

A/B-тестирование не следует приписывать наблюдательному сравнению групп. Ridge, Lasso и ElasticNet представлены в проекте 2. Навыки каждого проекта перечислены отдельно. Импорт библиотеки сам по себе не подтверждает владение всем её функционалом.

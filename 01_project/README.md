# Проект 1. Анализ рынка недвижимости

[← Roadmap](../README.md) · [Ноутбук](project.ipynb)

## Задача

Исследовать цены квартир, качество исходных данных и связь характеристик жилья с ценой.

## Навыки

В этом проекте использовались: **Pandas, EDA, очистка данных, кодирование категорий, MinMaxScaler, корреляции, критерий Краскела — Уоллиса**.

## Данные и запуск

Исходный файл: `solution.ipynb`. Ноутбук скопирован с сохранением кода и результатов. Откройте `project.ipynb`, проверьте пути в ячейках загрузки и выполните Restart Kernel → Run All.

Обнаруженные в коде имена файлов (включая возможные выходные и вспомогательные): `PAKA.jpg`, `lab_1.csv`.

Импортируемые модули: `IPython`, `PIL`, `matplotlib`, `numpy`, `pandas`, `scipy`, `seaborn`, `sklearn`. Стандартные модули Python отдельно устанавливать не нужно. Точные версии окружения в этой сборке не зафиксированы.

## Что и как решается

Ниже приведены методические разделы самого ноутбука, описывающие последовательность и обоснование решения.

### Подготовка и исследование
Проверка пропусков и дубликатов, нормализация категорий, обработка некорректных значений, кодирование ремонта, построение относительного этажа и доли жилой площади. Затем исследуются распределение цен, различия по ремонту и связь площади с ценой.

### Статистическая проверка
В коде используется scipy.stats.kruskal для сравнения цен по группам ремонта. Это наблюдательное исследование; рандомизированный A/B-эксперимент не проводился.
